## اكتشافات مهمة

1. **الروابط اللي جايبة الترتيب هي `aqdi.sa/blog/{slug}`**، مو `blogs.aqdi.sa`. وهذي حالياً تحوّل 301 إلى `blogs.aqdi.sa/blogs/{slug}` (تحققت على مقالين من الأعلى).
2. **`aqdi.sa/blog` (صفحة القائمة) ترجع 404.**
3. **بيانات `blogs.aqdi.sa` غير ظاهرة** لأنه مو خاصية منفصلة في Search Console، فنقرات الدومين الفرعي ما نشوفها. التوصية: خاصية نطاق `sc-domain:aqdi.sa` تغطي كل شي (فيه خانة مجانية فاضية).
4. **الروابط المتشابهة (16 مجموعة):** نسخ بنفس الـ slug مع `/` في الآخر أو `)` أو أخطاء إملائية، كلها بصفر نقرات. نحوّلها 301 للأصل وما نعتمد عليها.
5. **ملفات sitemap:** `sitemap.xml` فيه 13 رابط، و`blog-sitemap.xml` فيه 60 رابط مع **173 تحذير** (نراجعها قبل النقل). أرقام «indexed=0» في الاستجابة غير موثوقة.
6. **الموقع الرئيسي:** `www` ← `https://aqdi.sa` بـ 301، والجذر 200. robots.txt يسمح للجميع ويعلن `sitemap.xml`.
7. **الشهادات:** `*.aqdi.sa` صالحة حتى 2026-11-30، و`blogs.aqdi.sa` حتى 2026-12-02. أي نقل لازم يجدد/يصدر شهادات جديدة قبلها.
8. **⚠ يحتاج تحقق على جهازك:** أداة الفحص عرضت ترويسة `Location` للتحويل بحروف مشوّهة وحصل 404 في القفزة الثانية. غالباً هذا من الأداة (تفسّر الترويسة بترميز خاطئ) مو من السيرفر، لكن ما أقدر أجزم من هنا. اختبره بنفسك:

```bash
curl -sI "https://aqdi.sa/blog/%D8%AA%D8%B9%D8%B1%D9%81-%D8%B9%D9%84%D9%89-%D8%B7%D8%B1%D9%8A%D9%82%D8%A9-%D8%A7%D9%84%D8%AA%D8%B3%D8%AC%D9%8A%D9%84-%D9%81%D9%8A-%D9%85%D9%86%D8%B5%D8%A9-%D8%A5%D9%8A%D8%AC%D8%A7%D8%B1" | grep -i -E "^HTTP|^location"
```

## قاعدة «لا نفقد شي» (للتنفيذ لاحقاً)

1. كل رابط في `critical-urls-with-clicks.csv` يرجع **200** أو **301 مباشر (قفزة وحدة)** لنفس المحتوى بعد النقل.
2. الـ slug العربي يبقى حرفياً.
3. التحويل دائم 301 فقط (لا 302).
4. نقارن عنوان/وصف/Meta كل مقال بين القديم والجديد.
5. نرسل sitemap جديد في Search Console بعد النقل ونراقب الظهور أسبوعين.
6. ما نقفل الموقع القديم قبل ما الفحص يطلع صفر روابط مكسورة.
